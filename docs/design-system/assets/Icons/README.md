# Icons

Cloudscape's icon set (144 icons), 16×16 viewBox, 2px stroke, single ink `currentColor` (renders black inside `<img>`; inline the SVG so it takes the surrounding text color). Filled glyphs (`*-filled`, `status-*` dots) use `fill="currentColor"`.

Most used: `status-positive` · `status-negative` · `status-warning` · `status-info` · `status-in-progress` · `status-pending` · `status-stopped` (with StatusIndicator), `caret-down-filled` (select, button dropdowns), `angle-right` (breadcrumbs), `close` (dismiss), `search`, `settings`, `notification`, `user-profile`, `refresh`, `add-plus`, `external`, `copy`, `edit`, `remove`, `check` (selected option).
